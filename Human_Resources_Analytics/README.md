# Human Resources Analytics Dashboard

## Objective

The objective of this project is to develop an interactive Human Resources Analytics Dashboard using Power BI to analyze workforce data, improve HR processes, and support strategic decision-making.

## Project Overview

This dashboard provides insights into employee management, recruitment performance, employee turnover, satisfaction levels, and workforce trends. It helps organizations optimize HR operations and improve employee engagement through data-driven analysis.

## Key Features

* Recruitment Metrics Tracking
* Employee Turnover Analysis
* Employee Satisfaction Monitoring
* Performance Evaluation Analysis
* Department-wise Workforce Insights
* Predictive Analytics for Hiring Needs
* Interactive Filters and Dynamic Visualizations

## Tools & Technologies Used

* Power BI
* Microsoft Excel / CSV Dataset
* Data Transformation and Cleaning
* DAX Measures and Calculations

## Dashboard Insights

* Analyzed employee attrition and retention trends
* Evaluated recruitment efficiency and hiring patterns
* Identified factors affecting employee satisfaction
* Compared employee performance across departments
* Forecasted future hiring requirements using predictive analytics

## Benefits

* Supports efficient workforce planning
* Helps reduce employee turnover
* Improves recruitment decision-making
* Enhances employee performance analysis
* Enables data-driven HR strategies

## Files Included

* Power BI Dashboard File (.pbix)
* Dataset Files (.csv / .xlsx)
* Dashboard Screenshots
* Project Documentation

## Conclusion

The Human Resources Analytics Dashboard helps organizations monitor and optimize HR operations through interactive reporting and workforce analytics. This project demonstrates the practical application of Power BI in HR management and business intelligence.
