# Educational Performance and Resource Allocation Dashboard

## Objective

The objective of this project is to develop an interactive Power BI dashboard to evaluate student academic performance and optimize resource allocation in educational institutions through data-driven insights.

## Project Overview

This dashboard helps educational institutions monitor academic performance, analyze resource utilization, and identify areas requiring improvement. It supports better decision-making for effective education management and institutional planning.

## Key Features

* Student Academic Performance Analysis
* Subject-wise and Class-wise Performance Tracking
* Attendance and Performance Monitoring
* Resource Usage Analysis
* Identification of Resource Gaps
* Interactive Filters and Dynamic Visualizations
* Data-driven Decision Support

## Tools & Technologies Used

* Power BI
* Microsoft Excel / CSV Dataset
* Data Cleaning and Transformation
* DAX Measures and Calculations

## Dashboard Insights

* Analyzed student performance trends across subjects and classes
* Evaluated attendance and academic achievement patterns
* Identified underutilized and overutilized resources
* Detected gaps in educational resource allocation
* Supported institutional planning using analytical insights

## Benefits

* Helps improve student academic outcomes
* Supports efficient resource allocation
* Enhances educational planning and management
* Enables informed decision-making using real-time insights
* Improves monitoring of institutional performance

## Conclusion

The Educational Performance and Resource Allocation Dashboard provides comprehensive insights into academic performance and institutional resource management. This project demonstrates the effective use of Power BI for educational analytics and data-driven decision-making.
